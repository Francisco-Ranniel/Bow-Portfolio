# Photography & Videography Portfolio

A clean, editorial personal portfolio for photographers and videographers.

## 🔗 Live Website
> Add your GitHub Pages URL here after deployment

## 📸 Description
A single-page portfolio website featuring:
- **Hero** — full-height intro with featured image placeholder
- **About** — profile photo container + bio
- **Photography** — filterable grid (Portrait / Events / Landscape / Commercial)
- **Videography** — film reel section with video placeholders
- **Services** — four service offerings
- **Contact** — inquiry form

## 🛠 Technologies
- HTML5, CSS3, Vanilla JavaScript
- Google Fonts: Cormorant Garamond + Jost
- No frameworks, no build step

## ✏️ How to Personalise
1. Replace `[Your Name]` in `index.html`
2. Add your profile photo inside `.about-photo` div
3. Replace placeholder divs with `<img src="...">` or `<video>` tags
4. Update contact details (email, phone, social links)
5. Edit the About text and stats

## 🚀 Deploy to GitHub Pages
```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/portfolio.git
git push -u origin main
```
Then: Settings → Pages → Deploy from `main` branch root.
